---

🌌 Overview

JARVIS Calculator V3 is a futuristic, mobile-friendly computational interface designed to combine the simplicity of a calculator with the feel of an intelligent digital assistant.

The entire application runs from one HTML file.

No:

- ❌ npm
- ❌ Node.js
- ❌ Build tools
- ❌ External libraries
- ❌ Backend
- ❌ Database

Just open "index.html" and JARVIS comes online.

Instead of typing mathematical expressions manually, you can give JARVIS simple commands.
